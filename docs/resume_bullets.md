# 简历 Bullet

## 数据分析实习生方向

- 围绕 Olist 电商交易数据搭建运营分析看板，完成订单、商品、用户、支付、评价等多表清洗建模，沉淀订单宽表、商品明细宽表和用户宽表。
- 使用 Python/Pandas 构建 GMV、订单量、客单价、复购率、cohort 留存、品类贡献、取消率等指标体系，并通过 Streamlit/Plotly 展示经营趋势和结构变化。
- 设计异常诊断模块，基于滚动均值和 z-score 识别 GMV 异常波动，并通过月环比定位下滑品类，辅助运营复盘。
- 接入 OpenAI 兼容 LLM API，将 KPI 摘要、异常清单和履约指标自动生成运营日报/周报，同时提供模板兜底保证演示稳定。

## 运营数据分析方向

- 面向电商经营诊断场景，搭建“数据导入-指标分析-异常识别-复盘建议”的运营分析闭环，支持按日期、地区、品类筛选业务表现。
- 从 GMV 增长、品类贡献、用户复购、订单取消和履约体验多个维度定位经营问题，输出可落地的品类优化和履约改进建议。
- 设计 AI 复盘助手，自动生成核心结论、异常解释、可能原因、运营建议和后续验证指标，提高运营日报/周报产出效率。

## 产品运营方向

- 以运营同学的复盘流程为核心设计看板信息架构，拆分总览、经营诊断、品类商品、用户地域、履约体验和 AI 复盘页面。
- 针对 Olist 无曝光访问数据的限制，调整指标设计为履约率、取消率、复购率、留存和评分体验，保证产品分析口径真实可信。
- 通过模板兜底和 OpenAI 兼容接口配置，兼顾离线演示稳定性与真实 AI 能力扩展，形成可复用的数据运营工具原型。
