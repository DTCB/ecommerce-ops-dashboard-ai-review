# 项目复盘：电商运营数据分析看板 + AI复盘助手

## 项目背景

电商运营岗位需要同时理解交易数据、用户行为、商品结构和履约体验。单纯展示图表很难体现业务分析能力，因此本项目以“经营诊断”为主线，把 Olist 公开交易数据整理为可复用的数据模型，并在看板中输出异常识别和复盘建议。

## 解决的问题

- 原始 CSV 分散在订单、商品、用户、支付、评价等多张表中，直接分析成本高。
- 单一 GMV 趋势无法解释经营变化，需要结合品类、地域、复购、履约体验共同诊断。
- 运营日报/周报容易停留在人工描述，本项目用结构化指标摘要驱动 AI 或模板复盘，提升分析效率。

## 核心方法

- 数据层：将 Olist 原始表建模为订单宽表、商品明细宽表和用户宽表。
- 指标层：统一 GMV、订单量、客单价、复购率、取消率、留存、品类贡献等口径。
- 诊断层：用滚动均值和 z-score 标记 GMV 异常波动，用月环比识别下滑品类。
- 复盘层：将 KPI、异常、品类变化和履约体验整理为结构化上下文，再生成 AI/模板复盘。

## 项目亮点

- 没有强行编造 Olist 不具备的访问转化率，而是把诊断重点放在履约率、取消率、复购率和体验指标上。
- AI 不是简单“写一段话”，而是基于指标摘要和异常清单生成固定结构的经营复盘。
- 模板兜底保证演示稳定性，即使无 API Key 也能完整展示业务闭环。

## 结果沉淀

项目最终形成可运行 Demo、清晰 README、指标测试和复盘文档，可用于公开展示电商运营分析、指标建模和 AI 复盘能力。
